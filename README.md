# TaskFlow (native Kotlin + Jetpack Compose)

Everything from the old HTML/Capacitor app, rebuilt natively:
Home, Calendar (+ holidays), Upcoming, Reports, More (focus timer + fullscreen, interval reminders),
task / habit forms, swipe-to-delete, categories, screen lock (PIN / pattern / fingerprint),
notifications + alarms (Yes / No / Snooze buttons), per-item alert type: Notification (bell) or Reminder (alarm-style full screen, swipe to turn off), backup export / import.

Not in this version (not in the old app either): diary screen and badges (their data is still kept inside backups).
Not included yet: online holiday feed / gazette check (holidays are calculated offline).
