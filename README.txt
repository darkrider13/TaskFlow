HabitX - ব্যবহার

1. এই ফোল্ডারের সব ফাইল GitHub রিপোজিটরিতে আপলোড করো (.github ফোল্ডার ও debug.keystore সহ)।
2. Actions ট্যাবে "Build APK" চলবে। শেষ হলে রিপোজিটরির ডান পাশের Releases অংশে "latest" নামে নতুন APK আসবে।
3. প্রতিবার কোড বদলে আপলোড করলে ওই release নিজে থেকে নতুন APK দিয়ে আপডেট হবে। পুরোনো অ্যাপের ওপরেই ইনস্টল করলে ডেটা থাকবে।
4. আইকন assets ফোল্ডারে যোগ করা আছে (icon-only.png, icon-foreground.png, notification-icon.png)। বদলাতে চাইলে একই নামে ফাইল বদলে দাও।
